*Último día de rodaje de «Sombra en el Paraíso» (6 Jugadores)*

## 🌐 Publicación en GitHub Pages

1. Sube `index.html` y la carpeta `img/` a tu repositorio de GitHub (recuerda no subir este `README.md` si el repositorio es público y no quieres que nadie mire las contraseñas).
2. Activa **Settings → Pages → Deploy from branch (`main` / root)**.
3. Comparte la URL principal de GitHub Pages con los jugadores y entra tú como **Jack Miller** (`ronda54`) para controlar las rondas y el reloj desde el **Panel del Anfitrión**.
