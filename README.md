## 🌐 Publicación rápida en GitHub Pages

1. Sube `index.html` a un repositorio de GitHub (si no quieres que los demás vean las contraseñas en el repositorio público, no subas este `README.md` o súbelo a un repositorio privado si tienes Pages habilitado).
2. Activa **Settings → Pages → Deploy from branch (`main` / root)**.
3. Comparte con los jugadores la URL principal de GitHub Pages del repositorio (cargará `index.html` directamente).
4. Entra tú primero como **Jack Miller** (`ronda54`) para elegir desde el **Panel del Anfitrión** si jugáis en **Modo 6 jugadores** o **Modo 7 jugadores** y ajustar los minutos por ronda (12 min por defecto).
